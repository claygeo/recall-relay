# Recall Relay

**Every recall, every pantry, with proof.**

A Strands Agents application that runs a food bank's recall procedure across its partner pantries: it reads public FDA recall notices, matches them against the food bank's receiving and distribution ledger, drafts the notices, asks a human for one decision, relays the notices to every affected pantry, chases confirmations, and files the audit packet.

Built for the AWS "Agents for Humans" hackathon (Good Neighbor track), September 2026.
